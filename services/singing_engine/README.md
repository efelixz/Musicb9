# Singing Engine

## Responsabilidade
O "Core" da plataforma: motor de inferência que aplica a identidade vocal a uma melodia (Singing Voice Conversion).

## Funções Principais
- Inferência de voz cantada usando modelos pré-treinados.
- Ajuste de expressividade e emoção.
- Renderização de alta fidelidade para o perfil vocal do usuário.
