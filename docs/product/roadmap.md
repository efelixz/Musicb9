# Roadmap e Backlog Técnico

## Roadmap (5 Anos)
- **Horizonte 1 (Ano 1):** MVP com voz própria, letra, geração musical e exportação.
- **Horizonte 2 (Ano 2):** Editor visual avançado, biblioteca de estilos, melhoria de fidelidade.
- **Horizonte 3 (Ano 3):** Marketplace de vozes autorizadas, colaboração e API pública.

## Backlog MVP (Alta Prioridade)
- [ ] Cadastro e autenticação segura.
- [ ] Fluxo de consentimento de voz (Jurídico/Compliance).
- [ ] Captura vocal guiada (Gravação de amostras).
- [ ] Geração de perfil vocal inicial (Training/Embedding).
- [ ] Editor de letras e escolha de estilo/emoção.
- [ ] Geração de melodia via IA.
- [ ] Singing Engine (Renderização da voz do usuário).
- [ ] Mixagem e Masterização básica automática.
- [ ] Exportação (MP3/WAV).
- [ ] Sistema de créditos e billing.

## Backlog Secundário (Delighters)
- [ ] Harmonias automáticas e backvocals.
- [ ] Editor palavra por palavra (Ajuste fino de interpretação).
- [ ] Duetos com vozes autorizadas.
- [ ] API externa para integração B2B.
