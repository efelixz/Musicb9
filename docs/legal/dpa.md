# Acordo de Processamento de Dados (DPA) - Voicify AI

## 1. Escopo do Processamento
A Voicify processa dados biométricos de voz estritamente para a finalidade de síntese de canto assistida por IA, conforme instruído pelo usuário.

## 2. Instruções do Usuário
O usuário é o controlador dos dados de sua voz. A Voicify atua como operadora, executando o processamento apenas mediante o consentimento capturado no onboarding.

## 3. Localização dos Dados
Os dados são armazenados de forma segura em infraestrutura de nuvem certificada (AWS/S3), com criptografia de ponta a ponta.

## 4. Direitos do Titular
Garantimos o acesso, portabilidade e exclusão de todos os ativos vocais e projetos musicais vinculados à conta do usuário.
